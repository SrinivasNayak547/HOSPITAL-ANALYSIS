# 🏥 Hospital Analysis Using SQL

## 📌 Project Overview
The Hospital Analysis project focuses on analyzing hospital data using SQL to understand patient admissions, doctor performance, treatment details, and billing information. The goal is to extract meaningful insights and support better healthcare decision-making.

## 🎯 Objectives
- Analyze patient information and admission records.
- Track hospital admissions and discharges.
- Analyze doctor and department performance.
- Identify treatment and billing patterns.
- Generate meaningful insights using SQL queries.

## 🛠️ Tools & Technologies
- SQL Server
- Microsoft SQL Server Management Studio (SSMS)

## 📊 SQL Concepts Used
- SELECT & WHERE
- GROUP BY & ORDER BY
- Aggregate Functions
- JOINS
- Subqueries
- Common Table Expressions (CTEs)
- CASE Statements
- Window Functions

## 🔍 Key Analysis
- Total number of patients.
- Department-wise patient distribution.
- Doctor-wise patient analysis.
- Admission and discharge trends.
- Revenue and billing analysis.
- Identification of frequently used treatments.

## 💡 Key Learnings
- Improved SQL query-writing skills.
- Gained experience in handling healthcare datasets.
- Learned to extract insights using SQL.
- Developed analytical and problem-solving skills.


This project demonstrates the use of SQL for analyzing hospital data and transforming raw healthcare information into meaningful business insights.
